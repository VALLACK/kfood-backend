# 실사용 검증 채점 결과

대상: 부산 식당 메뉴판 사진 2장, 분석 결과 56건 (새우 알레르기·할랄·비건 프로필)
채점 방법: 사진에 인쇄된 실제 메뉴명·재료 표기와 한 줄씩 대조
측정일: 2026-09-30 · 표본이 2장이라 12장 전체 재검증 예정

---

## 1. 메뉴명 인식 정확도

| 구분 | 결과 |
|---|---|
| 사진 1 (해물탕 전문점, 38개) | 28/38 = 73.7% |
| 사진 2 (돼지국밥집, 9개) | 9/9 = 100% |
| 합계 | **37/47 = 78.7%** |
| 주요 메뉴(탕·찜·구이)만 | **20/20 = 100%** |

오인식 10건 중 8건이 사리·추가메뉴 칸(글자가 작고 두 줄로 붙음)에서 나왔다.
예: 칼국수→"랍국우", 라면→"란란", 감자수제비→"고만수제비".

## 2. 위험 메뉴 SAFE 오판 — 2건

| 프로필 | 메뉴 | 당시 판정 | 실제 | 원인 |
|---|---|---|---|---|
| 새우 알레르기 | 해물조개전골 | SAFE | 메뉴판 괄호에 `새우2` 인쇄 | 메뉴판 재료 문구를 읽지 않음 |
| 할랄 | 수육백반 | SAFE | 수육 = 돼지고기 | 메뉴명 규칙이 DB 매칭 메뉴에만 적용됨 |

두 건 모두 데이터 출처가 AI 추론이었고, 공공데이터·자체 DB로 판정한 건에서는 오판이 없었다.
같은 수육백반이 비건 프로필에서는 WARNING(돼지 수육)으로 나와, **AI 추론은 실행마다 결과가 달라질 수 있음**도 확인했다.

> 정정: 처음 채점에서는 돌게탕·돌게탕(대)도 오판으로 셌으나, 재확인 결과 `새우2`가 적힌 재료 줄은
> 바로 아래 해물탕의 것이었다. 돌게탕 칸에는 재료가 적혀 있지 않고, 돌게(게)는 새우와 다른 알레르기 항목이다.

## 3. 그 밖의 문제

- 해물탕 소·대: 메뉴판에 새우가 명시돼 있는데 "가능성"으로 처리돼 직원 질문이 생성됨 (안전 방향이나 부정확)
- 주류 9개(소주·백세주 등)가 분석 대상에 섞임
- 데이터 출처: 공공데이터 26.8% · 자체 DB 26.8% · **AI 추론 46.4%** — 오판은 전부 AI 추론 구간

## 4. 조치 (같은 날 반영)

| 문제 | 조치 |
|---|---|
| 메뉴판 재료 문구 미반영 | OCR이 메뉴별 괄호 재료(`note`)를 추출 → 메뉴판 표기를 최우선 근거로 확정 처리 |
| 수육 등 메뉴명 규칙 누락 | 메뉴명 규칙을 모든 경로에 적용, 수육·항정살·보쌈·족발·게 종류 등 추가 |
| 재료를 모르는데 SAFE | 공공데이터·AI 근거가 없으면 SAFE 대신 최소 "직원 확인" + 질문 생성 |
| 소·대 판정 불일치 | 같은 메뉴의 소·대가 재료 설명을 공유 |
| 주류 섞임 | 음료 제외 규칙 보강 (음식 이름은 제외되지 않게) |

재실행 확인(사진 1, 새우 알레르기): 해물조개전골 **SAFE → WARNING**, 해물탕 **CAUTION → WARNING**.
오판 사례는 전부 회귀 테스트로 고정했다 (`tests/test_menu_board.py`, `tests/test_review_fixes.py`).

## 4. 같이 고친 것

- **OCR 실패**: Groq 비전 모델은 분당 출력 1000토큰 제한(OTPM). 메뉴판 원문까지 받다가 초과 → 원문을 받지 않고 상한 1000, AI 생각 과정 끔, 한도 초과는 기다리지 않고 바로 실패(77초 → 즉시)
- 출력이 중간에 끊기면 완성된 메뉴까지는 살림
- **음료 미제외** 6종(에일, 토닉, 청하/별빛청하 등) → 분석 대상에서 제외
- 약한 판정(WARNING이어야 하는데 CAUTION) 개선: 낙새·낙삼새볶음(새=새우, 삼=삼겹살), 등심카츠, 크리스피 장펀

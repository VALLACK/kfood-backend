메뉴 136개를 추출해 판정 로직에 투입했다. OCR 단계는 제외하고 **메뉴명 → 재료·위험도 판정** 구간을 측정했다.

## 3. 1차 검증에서 발견한 오류와 조치
| 사례 | 문제 | 조치 후 |

| 해물아구찜 | 기준 레시피에 해산물 없어 새우 알레르기 SAFE | 메뉴명 '해물' 반영 → **CAUTION + 직원 질문** |
| 소고기우동 | 소고기 미반영 | 메뉴명 키워드 반영 → 할랄 CAUTION(인증 확인) |

## 4. 남은 개선 과제
1. **매칭률 62% 미달** — 중식·일식 메뉴 보강 필요 (자체 메뉴 DB 확장 또는 별도 데이터 확보)
2. **대표 레시피 선정** — '불고기'가 '불고기(닭고기)'로 잡히는 등 기본형 선택 규칙 개선 필요
3. **OCR 단계 포함 측정** — 본 측정은 메뉴명이 정확히 주어진 상태를 가정 (`scripts/evaluate_menus.py`로 사진부터 측정 가능)
4. **정답 채점** — 메뉴별 실제 재료 기준 정확도는 팀 수동 채점 필요
